# サンプルVault

これは、**ビジネスパーソン（プロダクトマネージャー）** を題材にしたObsidian Vaultのサンプルです。
AI秘書がどのような入力からどのような出力を生成するのか、雰囲気を掴むためのデモです。

## 登場人物（すべて架空）

- **山田健一**（主人公）：テクノソリューションズ社のプロダクトマネージャー
- **山田健太郎**：営業部長（健一の上司）
- **佐藤美咲**：営業チームリーダー
- **田中達也**：営業担当
- **中村翔太**：開発リーダー

## ディレクトリ構成

```
sample-vault/
├── GEMINI.md                    # AI秘書への指示書（リポジトリルートと同じ）
├── 0_Thoughts/Daily/            # 入力：日々のデイリーノート（AIは読まない設定）
│   └── 2026-05-20.md
├── meetings/                    # 入力：会議メモ
│   ├── 2026-05-20-sales-meeting.md
│   └── 2026-05-20-dev-sync.md
├── projects/                    # 入力：プロジェクトまとめ
│   └── project-a.md
├── knowledge/                   # 入力：知識ベース
│   └── competitor-analysis.md
└── gemini/                      # ← 出力：AIが生成したもの
    ├── daily-briefing.md             # メイン：今日のbriefing
    ├── nord-map.md                   # ナレッジマップ
    ├── task-database.md              # 抽出タスク一覧
    ├── project-database.md           # プロジェクト一覧
    ├── learning-from-feedback.md     # フィードバック学習ログ
    └── archive/                      # 過去版スナップショット
        └── daily-briefing-2026-05-20-v1.md
```

## 流れの例

1. **2026-05-20 (水)**：山田さん（架空）が一日メモを書く → `0_Thoughts/Daily/2026-05-20.md`
2. **2026-05-20 (水) 営業会議＆開発会議**：議事録を作成 → `meetings/` 配下
3. **2026-05-21 (木) 朝7時**：AI秘書が自動起動
   - 昨日との差分を分析
   - `gemini/daily-briefing.md` を更新
   - タスク・ナレッジマップ・プロジェクトDBを更新
4. **2026-05-21 (木) 山田さんが起床後にbriefingを確認**
   - 今日の優先タスクTop 3を把握
   - 「当日メモ欄」に思いつきを書く
   - 「フィードバック欄」にAIへのコメントを書く
5. **2026-05-22 (金) 朝7時**：また自動起動 → 昨日のフィードバックを学習して改善

これらのファイルを Obsidian で開いて、実際の見栄えを確認してみてください。
